Gerador de Config EAS

Importe qualquer projeto Expo e gere os arquivos prontos para virar APK

1. Importar Projeto (ZIP)

📁
Clique ou arraste o ZIP aqui
Qualquer projeto Expo (package.json + app.json)

2. Configurar seu App

📍 Onde achar: expo.dev → seu projeto → Settings → Project ID

3. Tipo de Build

✅ Arquivos gerados!

📋 Próximos passos:
1Extraia o ZIP gerado na pasta do seu projeto
2No terminal: npm install
3Faça login: npx eas login
4Gere o APK: eas build --profile preview --platform android
5Baixe o APK no link que aparecer no terminal
⚠️ Precisa ter Node.js e uma conta gratuita em expo.dev para funcionar.
