💻 CODE EDITOR
  Editor de código com IA integrada.
  Importe/exporte ZIPs. Suporte a HTML, CSS, JS, Python, etc.

📦 APK BUILDER
  Cole seu ZIP de projeto web e gere:
    → APK Android (via Android Studio ou GitHub Actions)
    → Executável de PC (via Electron — Windows/Mac/Linux)
  Orientação: retrato, paisagem ou ambos.

🔍 SITE EXTRACTOR
  Extraia scripts de cálculo de sites jurídicos.
  Usa proxies públicos — sem servidor Replit.
  Detecta: fórmulas, fetch/ajax, cálculos previdenciários.
