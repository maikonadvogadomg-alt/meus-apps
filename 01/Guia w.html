🚀 Iniciar Servidor (Windows)

Opção 1: Python (Mais Fácil)

1. Abra PowerShell na pasta do projeto
2. Digite o comando abaixo
python -m http.server 8000
3. Abra o navegador em: http://localhost:8000

Opção 2: Node.js

npx http-server

Opção 3: PHP

php -S localhost:8000

Opção 4: VS Code Live Server

1. Instale a extensão "Live Server" no VS Code
2. Clique com botão direito no index.html
3. Selecione "Open with Live Server"
Clique em qualquer comando para copiar para a área de transferência!
