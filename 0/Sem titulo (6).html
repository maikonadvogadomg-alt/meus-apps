🖥️ Guia: Criar Estrutura de Projeto com Terminal

1️⃣ O QUE É TERMINAL?

Terminal = Linha de Comando do Computador

É um programa onde você digita COMANDOS para o computador fazer coisas.

Você pode criar pastas, arquivos, instalar programas, etc.

Como abrir o Terminal:

🪟 Windows:

Clique em Iniciar → Digite cmd → Pressione Enter

Ou: Clique em Iniciar → Digite PowerShell → Pressione Enter

🍎 Mac:

Pressione Cmd + Espaço → Digite Terminal → Pressione Enter

🐧 Linux:

Pressione Ctrl + Alt + T

2️⃣ COMANDOS BÁSICOS

Criar uma Pasta:

mkdir meu-projeto

Cria uma pasta chamada "meu-projeto"

Entrar em uma Pasta:

cd meu-projeto

Entra dentro da pasta "meu-projeto"

Criar um Arquivo:

echo > index.html

Cria um arquivo vazio chamado "index.html"

Ver o que tem na Pasta:

dir (Windows) ls (Mac/Linux)

Mostra todos os arquivos e pastas

3️⃣ CRIAR ESTRUTURA MANUALMENTE (Passo a Passo)

Vamos criar essa estrutura:

/meu-projeto/ ├── index.html ├── css/ │ ├── style.css │ └── navbar.css ├── js/ │ ├── app.js │ ├── files.js │ └── editor.js └── assets/ └── imagens/

Passo 1: Criar a Pasta Principal

mkdir meu-projeto

Passo 2: Entrar na Pasta

cd meu-projeto

Passo 3: Criar as Subpastas

mkdir css mkdir js mkdir assets mkdir assets/imagens

Passo 4: Criar os Arquivos

echo > index.html echo > css/style.css echo > css/navbar.css echo > js/app.js echo > js/files.js echo > js/editor.js

Passo 5: Ver o Resultado

dir (Windows) ls -la (Mac/Linux)

4️⃣ CRIAR TUDO EM UM COMANDO (Mais Rápido)

Existe um jeito mais rápido!

Você pode criar TUDO com UM COMANDO SÓ:

Windows (PowerShell):

mkdir meu-projeto/css,meu-projeto/js,meu-projeto/assets/imagens

Mac/Linux (Bash):

mkdir -p meu-projeto/{css,js,assets/imagens}

A flag -p cria as pastas pai também!

5️⃣ USAR FERRAMENTAS AUTOMÁTICAS (Mais Fácil)

Existem ferramentas que criam a estrutura AUTOMATICAMENTE!

Você só precisa de Node.js instalado.

Opção 1: Create React App (Para Projetos React)

npx create-react-app meu-projeto

Cria um projeto React completo com estrutura pronta!

Opção 2: Vite (Mais Rápido)

npm create vite@latest meu-projeto

Cria um projeto moderno com Vite!

Opção 3: Scaffolding Customizado (Seu Próprio)

npm init -y

Cria um arquivo package.json para seu projeto!

6️⃣ SCRIPT AUTOMÁTICO (Cria Tudo de Vez)

Você pode criar um SCRIPT que faz tudo!

Crie um arquivo chamado criar-projeto.bat (Windows) ou criar-projeto.sh (Mac/Linux)

Windows (criar-projeto.bat):

@echo off mkdir %1 cd %1 mkdir css mkdir js mkdir assets mkdir assets\imagens echo. > index.html echo. > css\style.css echo. > js\app.js echo Projeto criado!

Como usar:

criar-projeto.bat meu-projeto

Mac/Linux (criar-projeto.sh):

#!/bin/bash mkdir -p $1/{css,js,assets/imagens} touch $1/index.html touch $1/css/style.css touch $1/js/app.js echo "Projeto criado!"

Como usar:

bash criar-projeto.sh meu-projeto

7️⃣ EXEMPLO PRÁTICO: CRIAR SEU EDITOR

Vamos criar a estrutura do seu editor:

/editor-juridico/ ├── index.html ├── css/ │ ├── style.css │ ├── navbar.css │ ├── sidebar.css │ ├── editor.css │ └── preview.css ├── js/ │ ├── app.js │ ├── files.js │ ├── editor.js │ ├── preview.js │ └── utils.js ├── assets/ │ ├── imagens/ │ └── icons/ └── README.md

Comando para criar (Mac/Linux):

mkdir -p editor-juridico/{css,js,assets/{imagens,icons}} cd editor-juridico touch index.html css/style.css css/navbar.css css/sidebar.css css/editor.css css/preview.css js/app.js js/files.js js/editor.js js/preview.js js/utils.js README.md

Comando para criar (Windows PowerShell):

mkdir editor-juridico\css,editor-juridico\js,editor-juridico\assets\imagens,editor-juridico\assets\icons cd editor-juridico New-Item -Path "." -Name "index.html" -ItemType "file" New-Item -Path "css" -Name "style.css" -ItemType "file"

9️⃣ RESUMO: QUAL USAR?

✅ Se você quer SIMPLES e RÁPIDO:

Use comandos manuais:

mkdir -p meu-projeto/{css,js} cd meu-projeto touch index.html css/style.css js/app.js

✅ Se você quer AUTOMÁTICO e PROFISSIONAL:

Use ferramentas:

npm create vite@latest meu-projeto

✅ Se você quer CUSTOMIZADO:

Crie seu próprio script (arquivo .bat ou .sh)

🔟 PASSO A PASSO FINAL

Para criar seu editor modular:

  1. Abra o Terminal
  2. Crie a pasta: mkdir editor-juridico
  3. Entre na pasta: cd editor-juridico
  4. Crie as subpastas: mkdir css js assets
  5. Crie os arquivos: touch index.html css/style.css js/app.js
  6. Abra no editor de código (VS Code)
  7. Comece a codar!
