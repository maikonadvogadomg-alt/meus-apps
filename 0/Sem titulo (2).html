🗺️ Guia: Descobrir e Replicar Estruturas de Projetos

1️⃣ O PROBLEMA QUE VOCÊ TEM

❌ O que você quer fazer:

  1. Pegar um projeto (ZIP ou pasta)
  2. Ver a estrutura (árvore de pastas)
  3. Usar essa estrutura no seu editor
  4. Criar as pastas automaticamente

✅ Solução:

Usar ferramentas para GERAR O MAPA da estrutura.

Depois usar esse mapa para CRIAR AS PASTAS automaticamente.

2️⃣ FERRAMENTAS PARA GERAR O MAPA (ÁRVORE)

Ferramenta 1: TREE (Comando Terminal)

Mostra a estrutura de pastas em forma de árvore.

Como usar (Windows):

tree C:\Users\Seu_Usuario\meu-projeto

Como usar (Mac/Linux):

tree ~/meu-projeto

Resultado:

meu-projeto/ ├── index.html ├── css/ │ ├── style.css │ └── navbar.css ├── js/ │ ├── app.js │ └── files.js └── assets/ └── imagens/

Nota: Se não funcionar, instale com:

brew install tree (Mac) choco install tree (Windows)

Ferramenta 2: DIR (Windows)

Comando nativo do Windows para listar pastas.

dir /s /b

Mostra todas as pastas e arquivos.

Ferramenta 3: LS (Mac/Linux)

Comando nativo para listar pastas.

ls -la

Mostra todos os arquivos e pastas.

Ferramenta 4: FIND (Buscar Tudo)

Encontra todos os arquivos e pastas.

find . -type f -o -type d

3️⃣ FERRAMENTAS ONLINE (Sem Terminal)

Opção 1: VS Code (Editor de Código)

Abra a pasta no VS Code e veja a árvore na esquerda!

📁 meu-projeto 📄 index.html 📁 css 📄 style.css 📁 js 📄 app.js

Você pode ver EXATAMENTE como está organizado.

Opção 2: Gerador de Árvore Online

Sites que geram árvore de estrutura:

  • tree.nathanfriend.io - Cole o texto e gera a árvore
  • ascii-tree-generator.com - Cria árvore em ASCII
  • github.com - Veja a estrutura direto no GitHub

4️⃣ PASSO A PASSO: DESCOBRIR ESTRUTURA

Você tem um projeto em ZIP. Como descobrir a estrutura?

Passo 1: Extrair o ZIP

unzip projeto.zip

Passo 2: Entrar na Pasta

cd projeto

Passo 3: Gerar o Mapa

tree -L 3 > estrutura.txt

Salva a estrutura em um arquivo chamado "estrutura.txt"

Passo 4: Ver o Mapa

cat estrutura.txt

5️⃣ CRIAR PASTAS A PARTIR DO MAPA

Agora que você tem o mapa, como criar as pastas?

Opção 1: Manualmente (Lento)

Você vê o mapa e cria cada pasta:

mkdir css mkdir js mkdir assets

Opção 2: Script Automático (Rápido)

Crie um script que lê o mapa e cria as pastas:

Arquivo: criar-estrutura.js

const fs = require('fs'); const path = require('path'); const estrutura = { 'css': [], 'js': [], 'assets': ['imagens', 'icons'] }; function criarPastas(obj, basePath = '.') { for (const [pasta, subpastas] of Object.entries(obj)) { const caminhoCompleto = path.join(basePath, pasta); if (!fs.existsSync(caminhoCompleto)) { fs.mkdirSync(caminhoCompleto, { recursive: true }); console.log(`✅ Criada: ${caminhoCompleto}`); } if (subpastas.length > 0) { subpastas.forEach(sub => { const subCaminho = path.join(caminhoCompleto, sub); if (!fs.existsSync(subCaminho)) { fs.mkdirSync(subCaminho, { recursive: true }); console.log(`✅ Criada: ${subCaminho}`); } }); } } } criarPastas(estrutura);

Como usar:

node criar-estrutura.js

6️⃣ CONVERTER MAPA EM COMANDO

Você tem esse mapa:

projeto/ ├── css/ ├── js/ ├── assets/ │ ├── imagens/ │ └── icons/ └── index.html

Converta para esse comando:

mkdir -p projeto/{css,js,assets/{imagens,icons}}

Ou para criar os arquivos também:

mkdir -p projeto/{css,js,assets/{imagens,icons}} touch projeto/index.html

7️⃣ FERRAMENTA PRONTA: GERAR ESTRUTURA

Aqui está um programa que faz TUDO:

Ele lê um mapa e cria as pastas automaticamente!

Arquivo: estrutura.json (O MAPA)

{ "nome": "meu-projeto", "pastas": [ "css", "js", { "nome": "assets", "subpastas": ["imagens", "icons"] } ], "arquivos": [ "index.html", "README.md" ] }

Arquivo: criar.js (O PROGRAMA)

const fs = require('fs'); const path = require('path'); const config = require('./estrutura.json'); function criar(obj, basePath = '.') { // Criar pastas obj.pastas.forEach(item => { if (typeof item === 'string') { const dir = path.join(basePath, item); if (!fs.existsSync(dir)) { fs.mkdirSync(dir, { recursive: true }); console.log(`✅ Pasta: ${dir}`); } } else if (typeof item === 'object') { const dir = path.join(basePath, item.nome); if (!fs.existsSync(dir)) { fs.mkdirSync(dir, { recursive: true }); } item.subpastas.forEach(sub => { const subDir = path.join(dir, sub); if (!fs.existsSync(subDir)) { fs.mkdirSync(subDir, { recursive: true }); console.log(`✅ Pasta: ${subDir}`); } }); } }); // Criar arquivos obj.arquivos.forEach(arquivo => { const filePath = path.join(basePath, arquivo); if (!fs.existsSync(filePath)) { fs.writeFileSync(filePath, ''); console.log(`✅ Arquivo: ${filePath}`); } }); } criar(config, config.nome); console.log('✅ Estrutura criada!');

Como usar:

node criar.js

8️⃣ RESUMO: COMO FAZER

Etapa Ferramenta Comando
1. Ver a estrutura VS Code ou Tree tree
2. Salvar o mapa Tree ou arquivo JSON tree > estrutura.txt
3. Converter para comando Manual ou script mkdir -p projeto/{...}
4. Criar as pastas Terminal ou Node.js node criar.js

Você tem um projeto em ZIP. Aqui está o passo a passo:

2️⃣ Ver a estrutura

3️⃣ Salvar em arquivo
