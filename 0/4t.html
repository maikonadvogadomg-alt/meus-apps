🧩 Módulos ### `core/utils.js` Funções auxiliares globais - `qs()` - querySelector - `qsa()` - querySelectorAll - `ls()` / `lsSet()` - localStorage - `toast()` - notificações - `dlBlob()` - download - `FICON()` - ícones por tipo ### `core/state.js` Estado global da aplicação - `State.files` - arquivos abertos - `State.currentFile` - arquivo ativo - `State.aiHistory` - histórico IA - `State.slots` - chaves API ### `core/storage.js` Persistência de dados - `Storage.createFile()` - `Storage.openFile()` - `Storage.saveFile()` - `Storage.deleteFile()` - `Storage.renameFile()` - `Storage.duplicateFile()` ### `modules/sidebar/sidebar.js` Árvore de arquivos - Criar/editar/deletar - Menu de contexto - Renderização dinâmica ### `modules/editor/editor.js` Editor de código - Números de linha - Sincronização de scroll - Atalhos de teclado - Renomear arquivos ### `modules/preview/preview.js` Preview ao vivo - 3 modos (off/split/full) - Minimizar/expandir - Redimensionável ### `modules/ai/ai.js` IA integrada - Chat interativo - Auto-detecção de chaves - Múltiplos provedores ### `modules/mapper/mapper.js` Análise de projetos - Detectar dependências - Mapear APIs - Identificar problemas - Gerar relatórios --- ## 🔌 API ### State ```javascript // Acessar estado State.files // { 'arquivo.js': 'conteúdo' } State.currentFile // 'arquivo.js' State.aiHistory // [ {role, content} ] // Modificar estado State.files['novo.js'] = 'console.log("oi")'; State.save(); // Salvar localStorage State.saveSlots(); // Salvar chaves ``` ### Storage ```javascript // Criar arquivo Storage.createFile('index.html'); // Abrir arquivo const content = Storage.openFile('index.html'); // Salvar Storage.saveFile(); // Deletar Storage.deleteFile('index.html'); // Renomear Storage.renameFile('old.js', 'new.js'); // Duplicar Storage.duplicateFile('original.js'); ``` ### Modules ```javascript // Sidebar SidebarModule.render(); SidebarModule.openFile('arquivo.js'); SidebarModule.createItem(); // Editor EditorModule.updateLineNums(); EditorModule.onInput(); EditorModule.rename(); // Preview PreviewModule.refresh(); PreviewModule.setMode('split'); PreviewModule.toggleMin(); // AI AIModule.send(); AIModule.sendWithCode(); AIModule.addMsg('user', 'Olá'); // Mapper MapperModule.analyze(event); MapperModule.render(); MapperModule.downloadMarkdown(); ``` --- ## 🐛 Troubleshooting ### Preview não funciona ``` ❌ Problema: Preview branco ✅ Solução: Certifique-se que o arquivo é HTML Clique em "⚡" para ativar preview ``` ### IA não responde ``` ❌ Problema: Erro "Nenhuma chave ativa" ✅ Solução: Clique em "🔑" e adicione sua chave API Escolha um provedor válido ``` ### Arquivo não salva ``` ❌ Problema: Mudanças desaparecem ✅ Solução: Pressione Ctrl+S Verifique se localStorage está ativado Tente em modo anônimo ``` ### Mapper não carrega ZIP ``` ❌ Problema: "JSZip não carregado" ✅ Solução: Verifique conexão com internet Recarregue a página Tente outro ZIP ``` ### Mobile não funciona bem ``` ❌ Problema: Abas não fecham/abrem ✅ Solução: Atualize o navegador Tente em modo paisagem Limpe cache (Ctrl+Shift+Delete) ``` --- ##
